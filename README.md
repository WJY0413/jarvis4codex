# Jarvis 0.2.6 Linux

Core version: 0.2.6. Linux cloud adapter: dot.1. Python distribution: 0.2.6+dot.1.

This Linux edition preserves the accepted exact-terminal observer fallback, adds the reviewed Task A revision 1 alias-cancellation, immutable request replay and owned-dispatch gates, integrates the shared bounded loopback HTTP listener recovery, isolates monitor terminal baselines, preserves failed notification outcomes and serializes bounded heartbeat execution per database.

Linux cloud execution requires a frozen explicit model and reasoning effort with verified runtime constraints. Project-config automatic model/effort/tier selection from the Windows edition is not implemented in this Linux adapter. The Windows thread-cwd LRU cache is not introduced.

The default transport remains stdio. Optional loopback HTTP recovery rebuilds the listener after completed lifespan cleanup with a process-lifetime three-attempt budget; it does not replay tool calls.

No credentials, operational state, private review packets, customer records or original runtime logs are included in the release source payload. Original full Jarvistest and publication status are recorded separately; this source identity alone is not an acceptance claim.
