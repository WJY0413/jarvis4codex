# Jarvis Loop Metrics (0.3.0 candidate, optional)

This is an offline local analysis Skill, not one of the 17 MCP tools. Read authorized saved Loop/Hold receipts and exact native token evidence, with missing values marked `not_measured`; do not estimate spend from quota percentage, model names or text. Keep attempts, retries, wall time, seat occupancy, output decisions and delivery separate. Research-specific quality metrics require their own business source and permission; no contact/company data is bundled here.

This candidate does not ship the old `metrics.py` because its sibling `workflow-token-observability-v2` dependency and research-specific input contract are not portable. Use this Skill only for interpretation of existing readbacks; live automated scoring and local script execution remain unverified. It cannot stop a Loop, qualify a result, or authorize further research.
