Zero tests executed there. This dot package is Linux-only; Windows users must stay on main/v0.2.5. No code was changed to hide or fix that platform issue in this already validated build. Native model shell/file tools remain disabled; controlled client file/form operations do not establish general filesystem parity. Interrupted campaign preparation still needs receipt-level inspection rather than trusting an issued-count status alone. No broader business-quality, cost, latency, production or operating-system parity claim is made.
